# 柔道 試合タイマー（全日本UI）

全国大会の会場に置かれている電光掲示板の並びをそのまま画面にした、
タッチ操作だけで動く柔道の試合タイマーです。`index.html` 1枚で動きます。

## 画面

```
┌──────────────────────────┬────────┐
│        1:38              │  抑 07 │   上段：試合時間／右に抑え込み時間
├──────────────────────────┴────────┤
│ 赤 │ I 0 │ W 1 │ Y 1 │ S1         │   赤選手の得点
├───────────────────────────────────┤
│ 白 │ I 0 │ W 0 │ Y 2 │ S2         │   白選手の得点
└───────────────────────────────────┘
```

遠くの観客席からでも読めるように、得点は文字で表します。

| 表示 | 意味 |
| --- | --- |
| **I** | 一本 |
| **W** | 技あり |
| **Y** | 有効 |
| **S1 / S2 / S3** | 指導1回／2回／3回（S3＝反則負け） |

## 操作（すべてタッチ）

| 場所 | タップ | ダブルタップ | 長押し |
| --- | --- | --- | --- |
| 試合時間 | はじめ／待て | 時間の編集画面 | － |
| 抑え込み | 上半分＝赤で開始／下半分＝白で開始、抑え込み中は「解けた」 | 00 に戻す | － |
| 得点セル | ＋1 | － | −1（訂正） |

上部のバーには、GS切替・**↩取消**（直前の操作を戻す）・次の試合・設定・
ヘルプ・全画面だけを置いています。「待て」「試合中」といった状態の文字は
出さず、時計の色で表します（緑＝試合中／黄＝待て／赤＝試合終了）。
ゴールデンスコア中は時計の横に大きく **GS** が点きます。

### 判定の自動処理

- 抑え込みは 20秒でI（一本）、10秒でW（技あり）、5秒でY（有効）。
  技ありを持っている側が10秒抑えたときは**合わせ技一本**として試合終了。
- 抑え込み中は加算される点が点滅し、「解けた」で確定します。
- ブザーが鳴るのは、抑え込みの一本・合わせ技一本・試合時間の終了の3つだけです。
  立技の一本と反則負けは審判の宣告で決まるので鳴りません。
- 「待て」で時計を止めると抑え込みも一緒に止まり（そのまま）、
  「はじめ」で一緒に動き出します（よし）。
- 技あり2つで合わせ技一本、指導3回で反則負け。その時点で試合終了です。
- 試合時間が0になっても抑え込み中は終了せず、解けた時点で終了します。
- ゴールデンスコア（GS）は加算表示で、先に取った側の勝ちです。

### 設定（⚙ または時計のダブルタップ）

試合時間／この試合の残り時間／抑え込みの3つのしきい値／有効(Y)の使用／
時計の加算・減算／ブザーの音量と断続パターン。設定は端末に保存されます。

## 動かし方

`index.html` をブラウザで開くだけです。全画面ボタン（⛶）で画面いっぱいに
表示でき、試合中は画面が消えないようにしています（Wake Lock 対応端末のみ）。
